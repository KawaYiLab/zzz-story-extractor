# 提取器与剧情 MCP 审查记录

审查日期：2026-10-21。范围为 zzz-story-extractor 的提取、清洗、缓存、导出、打包链路，以及 ikserver-rs 的 story 语料加载和只读 MCP 工具。没有审查后端其他业务模块，也没有上传或部署。

本轮发现并修复了会影响内容、来源可信度和查询稳定性的问题。下面的检查可以证明指定输入在这些链路中的行为，不能证明游戏的完整播放顺序已经恢复，或所有启发式判断都与游戏实际路线一致。

## 已修复的问题

| 问题 | 修复与验证 |
| --- | --- |
| 重复提取残留旧 supplement、lore、章节或格式文件 | 发现已有保留产物时，在读取输入和写文件前拒绝复用，要求新输出目录；独立设定提取也拒绝已有 lore。旧文件保留。 |
| 相似度阈值误删不同意思的台词 | 地址对要求已知兼容说话人与完全等价措辞；主角台词配对要求文字一致。“不能/能”、不同 NPC 相似台词等反例保留。 |
| 主角名字按后缀猜测、NPC 重复被当成复制块 | 使用 TextMap 已知服装身份；未知说话人、道具“门铃”、相邻 NPC 重复与缺乏分支证明的复制块保留。 |
| 已删除候选再次被拿来配对 | 主角配对跳过已经删除的候选。每次删减仍写原因、原文与配对来源，允许回查多步删减链。 |
| 布局文本清洗把行内文字挪到句尾 | 每组布局变体在原位置选取；前缀、句中内容、后缀的位置有回归测试。 |
| 说话人缓存只绑定目录、升级后复用旧映射 | 指纹包含完整 TextMap、别名表、解析代码、Perform、游戏路径/版本与资源文件名、大小、修改时间。缺少指纹或输入变化时重建，缓存原子写入。 |
| 将上游最新版本标在旧本地数据上 | 下载先固定同一提交，整个快照下载完才替换；来源证明包含提交、版本与全部输入哈希。无法核验时 source_version=unknown。已有证明失配的默认缓存要求刷新。 |
| Comic 导出把独立片段串在一起 | 每条 Comic 有来源标题及未关联上下文提示，其他补充类型保留片段边界。 |
| 只校验主线重复 ID | 主线与补充共同检查缺失、无效与重复 ID。 |
| 完整性校验只比键，且 python -O 跳过 assert | 改成始终执行的显式检查；核对输入哈希/语言/范围/模式、候选去向、原文、稳定 ID、配对与姓名原文。完整性模式增加 name_candidates.jsonl。 |
| JSON 数字小数被截断、超大数饱和转换、目录偏移溢出 | 数字参数只接受范围内整数，兼容数字字符串；目录分页用饱和运算，极大 offset 不崩溃。 |
| 续读丢失 limit/maxChars/lineNumbers 等偏好 | 同篇、下一篇及下一组的续读均保留显式有效参数；超长下一篇标题不再产生“第 1-0 行”空块。 |
| 未压缩语料包绕过 max_bytes | gzip 和普通 JSON 均检查字节上限。 |
| 旧小数章节顺序无法被后端直读，混合比例可能再次乘十 | Python 打包和 Rust 直读均支持旧比例迁移；新清单 chapter_order_scale=10，显式新比例拒绝小数。 |
| 全库/篇内标题 AND 不一致、标题命中缺少续读入口 | 两种范围采用相同元数据条件，标题命中提供读取入口；篇内也提示超过 8 词的截断。 |
| 模糊重名章节选中第一个、身份命中看似原文命中 | 重名或模糊歧义要求精确分组 ID；仅说话人名/身份命中时显式标注。 |
| manifest 读取错误被当成缺省 | 只有文件不存在可以缺省；其他读取或解析失败明确报错。 |
| 覆盖率包含已经删掉的配音候选 | 增加 has_voice，覆盖率按最终保留行计算。非法提取格式、limit 和覆盖率阈值在读取数据前报错。 |

关键 bug 均先用失败测试复现再修复。原有用户修改保留，未执行 Git 回滚、提交、推送或部署。

## 保留的实际边界

- 850 个 GalGame 场景中，698 个有档案位置、287 个解析到任务名；实际剧情时间先后确认数仍为 0。Chapter230 的 29 个演出场景没有可靠任务关联，不能按目录拼接实际流程。
- 2,451 条 Comic 仍是未关联片段。CS 的精确重复与称呼配对仍属于可审计的默认筛选，不是已确认播放节点。
- 默认采用哲视角并保留不确定项，不是严格单一路线。精确相同的主角台词也需要游戏路线证据才能完全排除真实重复；正式考据优先对照完整性模式和原文。
- 场景名单与共同出场可能含道具、占位名，例如“中心喷泉”；角色身份只合并明确已知形态。没有证据的名称不硬编码成角色或排除项。
- 说话人中仍有 scene_alias/scene_name 的低置信度推断，完整性模式关闭这些场景猜测。Perform 扫描是资源字符串解析，不等价于完整运行时节点解释。
- 资源缓存用文件元数据检测二进制更新；保留文件名、大小和修改时间的手动修改需要显式刷新。没有加跨进程导出锁；并发提取应使用不同 --out。
- 没有比例标记的旧自定义混合包存在歧义，须由数据作者修正比例清单。当前旧比例迁移支持历史十分位顺序，不接受无法无损换算的任意小数。
- maxChars 是标题与正文预算；为推进游标，单次首行可超预算，末尾续读提示不计入。数字范围钳制与整数要求已在参数和续读行为中验证。
- 下载固定提交和失败保留旧缓存的逻辑使用隔离测试验证；本轮没有联网刷新整套真实数据，也没有线上部署验证。大语料、语言回退及未知未来版本仍需对应样本，无法用本机 CHS 语料证明全部版本行为。

这些边界已在数据、工具结果或说明中明确表达；当前没有已复现且仍未修复的阻断问题。
